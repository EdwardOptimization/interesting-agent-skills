# README Intro Options

Use these as drop-in alternatives for the opening paragraphs of `README.md`.
The skill directory names and skill identifiers should stay in English.

## Option 1: Minimal

Interesting Agent Skills is a small incubator for reusable agent behavior
skills. It collects compact `SKILL.md` packages that help agents move faster,
stop sooner, debug more carefully, explore more creatively, or avoid common
work loops.

## Option 2: Curator

This repository is a curated shelf for agent skills that are too useful,
strange, or behaviorally sharp to leave inside one chat session. Each skill is a
portable instruction package with a narrow trigger, a repeatable workflow, and a
clear boundary for when it should stop.

## Option 3: Research

Interesting Agent Skills is an experimental collection for studying and shaping
agent behavior. The focus is not on domain knowledge alone, but on control
patterns: when an agent should seek evidence, delay action, take a quick win,
stop a loop, or convert a vague intent into an observable artifact.

## Option 4: Playful

This is a workshop for agent instincts. Some skills make the agent sprint,
others make it pause; some create momentum, others prevent overwork. The point
is to make useful behavior patterns explicit enough to reuse, test, and improve.

## Option 5: Public Release

Interesting Agent Skills is an open collection of reusable agent skills for
coding assistants and general-purpose AI agents. The repository favors small,
auditable skills with clear triggers, practical workflows, and minimal
dependencies. Skills are designed to be copied into local agent runtimes and
adapted safely.

## Option 6: Personal Incubator

This is a personal incubator for unusual, useful, and experimental agent
skills. It is broader than project-specific skill packs and is meant for ideas
that deserve to be kept, tested, and refined before they are promoted into a
public package or a production workflow.
